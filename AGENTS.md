# Project Instructions

Before working in this project, read `CLAUDE.md`.

Follow the conventions and warnings in `CLAUDE.md` unless the user explicitly says otherwise.

When adding or changing dependencies for IP3200 lectures, update this project's
Conda environment definition (`IP3200/environment.yml`) and make sure the actual
`IP3200` Conda environment is updated too. Do not install packages only into a
parent or unrelated environment; `quarto preview` for this project must work
from the IP3200 environment.
