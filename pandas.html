NumPyの表に名前をつける

Pandasとは

  • Pandasは 表形式データ（tabular data） を扱うためのライブラリ
    • Excelの表、CSV、実験結果、アンケート結果など
    • データ分析の入口で非常によく使う
  • NumPyの ndarray と同じく、Pythonの標準機能ではない

ターミナルからインストール：

pip install pandas

冒頭で import（pd としてインポートするのが一般的）：

import pandas as pd

今回のゴール

  • DataFrame / Series / index / columns を理解する
  • 集計結果を matplotlibで可視化 できるようにする

クイズ：田中さんの数学Iの点は？

  • 2人の生徒（田中・佐藤）の3科目（現代文・数学I・英会話）の点数がある
import numpy as np

arr = np.array([
    [80, 70, 90],
    [65, 75, 85],
])
  • 「田中さんの数学Iの点」を取り出すコードを書け

答え：arr[0, 1] …… で合ってる？自信ある？

  • 田中さんが0行目、数学Iが1列目という情報は 配列のどこにも書いていない
  • 取り出した 70 も、画面に出るのはただの数字 — 何の70点か分からない
  • 計算はNumPyで十分。困るのは 意味（名前）の管理
  • 表に 名前 をつけたもの、それが今日の DataFrame

DataFrameとは

  • Pandasの主役となる、名前つきの表（テーブル, table）
  • データ ＋ 行の名前（index）＋ 列の名前（columns）の3点セット
  • 行・列に名前をつけて表を扱う考え方は、Excelやデータベースなど多くの道具に共通
現代文 数学I 英会話
田中 80 70 90
佐藤 65 75 85

上端の見出し（現代文・数学I・英会話）が columns、左端の見出し（田中・佐藤）が index

pandasの基本はDataFrameなので用語を覚えよう

DataFrame ＝ データ ＋ index（行の名前）＋ columns（列の名前）

ndarrayからDataFrameを作る

  • pd.DataFrame() に ndarray を渡す
  • 最初は列名も行名も指定しない
import numpy as np
import pandas as pd

arr = np.array([
    [80, 70, 90],
    [65, 75, 85],
])

df = pd.DataFrame(arr)
print(df)
    0   1   2
0  80  70  90
1  65  75  85

DataFrame は表として表示され、左端と上端に 0, 1, 2, ... の番号が自動でつく

indexとcolumnsを確認

  • 行の名前を index
  • 列の名前を columns という
  • 指定しない場合は、どちらも自動で番号が振られる
import numpy as np
import pandas as pd

arr = np.array([[80, 70, 90], [65, 75, 85]])
df = pd.DataFrame(arr)

print(df.index)
print(df.columns)
RangeIndex(start=0, stop=2, step=1)
RangeIndex(start=0, stop=3, step=1)

自動でつく番号

  • RangeIndex(start=0, stop=2, step=1) は「0から1までの行番号」
  • RangeIndex(start=0, stop=3, step=1) は「0から2までの列番号」
  • Pythonの range() と同じく、stop の値は含まない

columnsを指定する

  • 列の意味が分かるように columns= を指定する
  • これだけで表がかなり読みやすくなる
import numpy as np
import pandas as pd

arr = np.array([[80, 70, 90], [65, 75, 85]])
df = pd.DataFrame(arr, columns=["現代文", "数学I", "英会話"])

print(df)
   現代文  数学I  英会話
0   80   70   90
1   65   75   85

もう df[1] ではなく df["数学I"]。「何列目か」ではなく「何の列か」で読める

indexも指定する

  • 行の意味が分かるように index= も指定する
  • この例では、行名を生徒名にする
import numpy as np
import pandas as pd

arr = np.array([[80, 70, 90], [65, 75, 85]])
df = pd.DataFrame(arr, columns=["現代文", "数学I", "英会話"], index=["田中", "佐藤"])

print(df)
    現代文  数学I  英会話
田中   80   70   90
佐藤   65   75   85

これで数字の並びに「誰の・何の点か」という意味がついた

名前があると何がうれしい？

  • df["数学I"] と書くと、数学Iの列だけ取り出せる
  • df.mean() と書くと、列ごとの平均が計算できる
  • 出力にも列名が残るので、結果を読み間違えにくい
import numpy as np
import pandas as pd

arr = np.array([[80, 70, 90], [65, 75, 85]])
df = pd.DataFrame(arr, columns=["現代文", "数学I", "英会話"], index=["田中", "佐藤"])

print(df.mean())
現代文    72.5
数学I    72.5
英会話    87.5
dtype: float64

名前つきの表が強い

  • axis=0 のような番号指定より読みやすい場面が多い
  • データ分析では 名前つきの表（DataFrame） が効く

  • DataFrameは 表
  • Seriesは 1列
  • Seriesにも index がある

  • Seriesは値に index がついている

  • それぞれの条件を丸括弧で囲む

df = pd.read_csv("data/students.csv")

print(df[
    (df["学科"] == "情報")
    & (df["数学I"] >= 80)
])

and ではなく &

  • Pandasの条件抽出では and ではなく &
  • 条件ごとに丸括弧をつける
  • この書き方は最初だけ少し変だが、よく使う

Tweak：AND と OR で「絞る」と「広がる」

  • 前ページのコード を1か所ずつ変えて実行
  • 条件式だけ実行する（df[...] を外す）→ 各行に True/False が返る
  • & を | にする（「両方」→「どちらか一方」で残る行が増える）
  • 数学Iの基準を反転する（80点未満）
  • 英会話も80点以上、と条件を足す

matplotlibで棒グラフにする

  • groupby() で作った avg（Series）を棒グラフにする
  • Series を index と values に分けて matplotlib に渡す
  • 縦軸は ylim(0, 100) で0点〜満点に固定（棒グラフは0から見せる）
import pandas as pd
import matplotlib.pyplot as plt
import japanize_matplotlib

df = pd.read_csv("data/students.csv")
subjects = ["現代文", "数学I", "英会話", "物理"]
df["平均点"] = df[subjects].mean(axis=1)
avg = df.groupby("学科")["平均点"].mean()

plt.bar(avg.index, avg.values)
plt.xlabel("学科")
plt.ylabel("平均点")
plt.title("学科ごとの平均点")
plt.ylim(0, 100)
plt.show()

演習：実データで明治の東京 vs 21世紀の東京

気象庁が公開している東京150年分の年平均気温をCSVで読み込み、明治の東京と21世紀の東京は平均で何度ちがうのかを自分のコードで確かめよ。

  1. tokyo_temp_annual.csv をダウンロードして data フォルダに置く
  2. pd.read_csv() で読み込み、columns で列名を確認
  3. 条件抽出で 明治（1911年以前） と 21世紀（2000年以降） の行に分ける
  4. それぞれの気温の平均を比較（差分値も表示）
解答例を見る 
import pandas as pd

df_temp = pd.read_csv("data/tokyo_temp_annual.csv")
print(df_temp.columns)  # (1) 列名を確認 → year と temp

meiji  = df_temp[df_temp["year"] <= 1911]
recent = df_temp[df_temp["year"] >= 2000]

meiji_avg  = meiji["temp"].mean()
recent_avg = recent["temp"].mean()
print(f"明治の東京   : {meiji_avg:.1f} ℃")
print(f"21世紀の東京 : {recent_avg:.1f} ℃")
print(f"差           : {recent_avg - meiji_avg:.1f} ℃")

列名で読み書きできる強さ

  • 150行のデータでも、絞り込み1行＋平均1行で答えが出る
  • NumPyの「何列目が年だっけ？」が、Pandasでは 列名 で済む
