まずは可視化する

  • 数値だけでは見落とすので まず描く — 可視化章 の大原則
  • 同じURL/ヘッダーで取得したあと plt.plot(views) するだけ
コードを見る 
import requests
import matplotlib.pyplot as plt
import japanize_matplotlib
import numpy as np

url = ("https://wikimedia.org/api/rest_v1/metrics/pageviews/per-article/"
       "ja.wikipedia/all-access/user/"
       "七夕/daily/20250101/20251231")
headers = {"User-Agent": "example.com/lesson"}
response = requests.get(url, headers=headers)
data = response.json()

views = np.array([item["views"] for item in data["items"]])

plt.plot(views)
plt.title("「七夕」の閲覧数（2025年）")
plt.xlabel("日数")
plt.ylabel("閲覧数")
plt.show()

1日だけ突出している

  • ほぼ平坦な中、1日だけ大きな山 — 数値だけ見ていると気づけない（アンスコムの教訓と同じ）
  • そして見覚えがあるはず：可視化編の冒頭で見せた謎の図は、実はこのデータ

山の正体：「いつ」を特定する

  • 山の 高さ は max()。知りたいのは 「いつ」
  • np.argmax() で インデックス を取り、同じインデックスで dates を引く
max_i = np.argmax(views)
print(f"{dates[max_i]} に {views[max_i]} 回")

クイズ

記事は「七夕」。47,656回も読まれたその1日は、何月何日だと思う？

2025070700 に 47656 回
  • 2025年7月7日 — 七夕の当日
  • みんな、行事の当日にその行事を調べる
    • 「七夕って何の日？」「短冊はなぜ？」— 検索が記事に殺到する
  • 1年分の人間の行動が、API経由の数列ひとつに写っている

よく見ると、もう一つ山がある

  • y軸を拡大すると、8月29日にも小さな山（2,291回）— 七夕でもないのに、なぜ？

小さな異変の発見と解釈

  • 小さな山の正体は？ グラフをドラッグで拡大して確かめよう
  • 正体：伝統的七夕 — 旧暦7月7日にあたる日（2025年は8月29日）
    • 国立天文台が毎年発表している。7月7日は梅雨だが、旧暦の七夕は夏空で天の川が見える
  • ズームしないと見えない発見もある — 軸の範囲は「正直さ」だけでなく「発見」の道具でもある

まとめ

やりたいこと コード
まず描く plt.plot(views)
最大値の位置 max_i = np.argmax(views)
位置から日付 dates[max_i]（同じindexの配列をリンク）

  • 統計量で「おかしい」と気づき、図で正体を突き止める
  • 大原則 Always plot your data first. は API由来のデータ にもそのまま効く

演習：1枚のグラフに2本の折れ線

前回の演習で取得した views_desktop と views_mobile_web を、同じグラフに重ねて比較せよ。

  1. plt.plot() を2回呼ぶ — それだけで重なる
  2. グラフの タイトルに max / min / mean を表示

やってはいけない

  • 軸を揃えず2枚並べる → 比較しづらい
  • 軸の範囲を片方だけ狭める → 印象操作（matplotlib章 の「y軸の罠」参照）
解答例を見る 
import requests
import matplotlib.pyplot as plt
import japanize_matplotlib
import numpy as np

headers = {"User-Agent": "example.com/lesson"}
article = "七夕"
base = ("https://wikimedia.org/api/rest_v1/metrics/pageviews/per-article/"
        f"ja.wikipedia/{{access}}/user/{article}/daily/20250101/20251231")

def fetch_views(access):
    url = base.format(access=access)
    data = requests.get(url, headers=headers).json()
    return np.array([item["views"] for item in data["items"]])

views_desktop    = fetch_views("desktop")
views_mobile_web = fetch_views("mobile-web")

plt.plot(views_desktop,    label="desktop")
plt.plot(views_mobile_web, label="mobile-web")
plt.legend()

title = (f"desktop: max={views_desktop.max()}, mean={views_desktop.mean():.1f}  "
         f"mobile: max={views_mobile_web.max()}, mean={views_mobile_web.mean():.1f}")
plt.title(title)
plt.xlabel("日数")
plt.ylabel("閲覧数")
plt.show()

演習：富士山には山があるか

「七夕」のコードの記事名を 富士山 に変えるだけで2025年1年分を取得して描き、次の問いに答えよ。

  • 問い：七夕のような 鋭い山（スパイク） はあるか？
  • 問い：スパイクがないなら、何が見えるか？ 自分の言葉で説明せよ
解答例を見る 
import requests
import matplotlib.pyplot as plt
import japanize_matplotlib
import numpy as np

url = ("https://wikimedia.org/api/rest_v1/metrics/pageviews/per-article/"
       "ja.wikipedia/all-access/user/"
       "富士山/daily/20250101/20251231")
headers = {"User-Agent": "example.com/lesson"}
response = requests.get(url, headers=headers)
data = response.json()

views = np.array([item["views"] for item in data["items"]])

plt.plot(views)
plt.title("「富士山」の閲覧数（2025年）")
plt.xlabel("日数")
plt.ylabel("閲覧数")
plt.show()

種明かし：針はない。でも「波」がある

  • 七夕のような数百倍のスパイクは ない（最大でも中央値の約3倍）
  • 代わりに 8月（登山シーズン）と1〜2月 が高い、ゆるやかな波
    • 夏が高いのは分かる。冬はなぜ高い？ — 考えてみよう
  • スパイクだけが発見ではない。波（季節性）も、データが教えてくれる人間の行動
