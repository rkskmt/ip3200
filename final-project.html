最終課題：オリジナルアプリ

  • NiceGUIで API+SPA のオリジナルアプリ を作って提出する
  • 企画案・ワイヤーフレーム・ソースコード・紹介スライドを提出する

この資料の 3画面テンプレート を動かし、自分の企画に合わせて変更する

テーマ例：診断・ゲーム系

系統 例
診断系 推し診断「あなたに合う推しのタイプは？」 ／ 勉強法診断 ／ 進路適性診断「理系？文系？」 ／ 部活診断
ゲーム系 三択クイズ（雑学・都道府県） ／ 心理テスト ／ 運試し（今日の運勢・おみくじ） ／ 2択選択ゲーム「あなたはどっち派？」

トップ・質問・結果の3画面に対応させられる。質問と結果をJSONに用意し、回答の記録や結果を決める処理をPythonで追加する

テーマ例：実用・創作系

系統 例
実用ツール系 テスト点数計算機（平均・合計） ／ 偏差値計算 ／ BMI計算+アドバイス ／ バイト時給計算機
創作・エンタメ系 ランダム決め（今日の昼飯・掃除当番） ／ 2つ名ジェネレーター（名前 → 面白い2つ名）

企画に合わせて3画面を変える

  • テンプレートは 表示するコンテナを切り替える仕組み
  • トップ・メイン・結果という名前や、画面の中身は変更してよい
企画 画面の例
診断アプリ トップ → 質問 → 結果
時間割アプリ 曜日選択 → 授業一覧 → 授業詳細
課題管理アプリ ホーム → 課題一覧 → 追加フォーム

ワイヤーフレームで考えた画面をもとに、必要な画面へ変更する。入力の保存や計算など、企画に必要な処理は自分で追加する

提出物：zipに4点

  • ファイル名は 「学籍番号_名前.zip」
内容 形式
1 635法などのカードで考えた 企画案 の写真（グループで発想したもの） PDF
2 Miroで作った ワイヤーフレーム のスクショ PDF
3 テンプレートを元に実装した ソースコード（api.py、main.py、.json） zip
4 アプリを紹介する スライド1枚（タイトル・特徴・スクショ程度でOK） PDF

3のzipは「入れ子」構造

api.py、main.py、.json をまとめたzipを、提出zipの中に入れる。==解凍して api.py、main.py の順に実行するだけで動く== ことを提出前に必ず確認する

ルール

  • テンプレートに付け足す形 で実装する
    • 文字・レイアウト変更、ボタン追加、遷移画面追加はOK
    • 構造を大きく変える／ライブラリを増やすのはNG
    • 生成AIの出力の丸写しはNG
  • 遷移画面は3画面以上
  • 使用できるライブラリは、NumPy や Requests など 授業で使ったもの と、math など pip install が不要なもの
  • ワイヤーフレームと実装は、方向性が合っていれば同一でなくてよい（見た目に過度にこだわらない）
  • 質問や助け合いは可。助けてもらったら、紹介スライドに協力者の名前と協力内容を書く

データはJSONに保存する

  • 表示するコンテンツは JSONに書き、APIから取得 する
    • JSONを編集するだけでアプリを変更・拡張できる 状態にする
    • 質問文や結果文を ui.label("...") に直接書かない（ハードコード、hard-coding）
    • ボタンの「スタート」などコンテンツ以外のラベルはハードコードOK
  • JSONへの 書き込みも可

データと画面の分離

質問を1問追加する場合はJSONを変更する。質問を順に表示する処理は、リストを読み取る形にしておけば共通で使える

評価基準

  • 提出物の内容とフォーマットが 指定通り
  • 公序良俗 に反していない
  • 生成AIの丸写しではなく、テンプレートに沿って 実装されている
  • エラーなく実行できる

提出前の確認

zipを別のフォルダに解凍し直し、api.py と main.py を実行する。JSONファイルの同梱、画面遷移、データ読み込みを確認する

テンプレートの構造

  • api.py：JSONを読み、URLごとにデータを返す
  • main.py：3画面を表示し、requests でAPIからデータを取得する

画面の表示・非表示を切り替える

  • 3画面 = 3つの ui.column()。set_visibility() で1つだけ表示 して画面遷移に見せる
def show_screen(screen_name):
    top_screen.set_visibility(screen_name == "top")
    main_screen.set_visibility(screen_name == "main")
    result_screen.set_visibility(screen_name == "result")

def show_main():
    show_screen("main")

ui.button("スタート", on_click=show_main)

screen_name == "top" は True / False になる。指定した画面だけ表示し、他の画面は非表示にする

移動先ごとに関数を作る

on_click には関数を カッコを付けずに 渡す。on_click=show_screen("main") と書くと、ボタンを作る時点で実行される

データファイルを用意する

  • data.json をダウンロードし、api.py と同じフォルダに置く
  • items の各要素が、画面に表示するデータ
{
  "items": [
    {"id": 1, "name": "サンプル1", "message": "1件目のメッセージ"},
    {"id": 2, "name": "サンプル2", "message": "2件目のメッセージ"},
    {"id": 3, "name": "サンプル3", "message": "3件目のメッセージ"}
  ]
}

テンプレート：api.py

URL 返すデータ
/api/data JSON全体
/api/item?id=1 id が1のデータ
api.py を表示 
"""
API server for the final project. Start this file first.
"""

from fastapi import FastAPI
from pathlib import Path
import json
import uvicorn

DATA_FILE = Path(__file__).parent / "data.json"   # Resolve data.json beside this script.

api = FastAPI()

# ========================================
# API endpoints
# ========================================
def get_data():
    with open(DATA_FILE, "r", encoding="utf-8") as f:
        return json.load(f)

def get_item(id: int):
    for item in get_data()["items"]:
        if item["id"] == id:
            return item
    return {"error": "Not found"}

api.add_api_route("/api/data", get_data)
api.add_api_route("/api/item", get_item)

uvicorn.run(api, port=8000)

テンプレート：main.py

api.py、main.py、data.json を同じフォルダに保存し、api.py、main.py の順に別々のターミナルで起動して、3画面の遷移と「データ読み込み」を確かめてから改造を始めよ。

main.py を表示 
"""
NiceGUI SPA template with three screens. Start api.py first.
"""

from nicegui import ui
import requests

API_URL = "http://127.0.0.1:8000/api"

# ========================================
# Screen switching
# ========================================
def show_screen(screen_name):
    top_screen.set_visibility(screen_name == "top")
    main_screen.set_visibility(screen_name == "main")
    result_screen.set_visibility(screen_name == "result")

def show_top():
    show_screen("top")

def show_main():
    show_screen("main")

def show_result():
    show_screen("result")

# ========================================
# Top screen
# ========================================
with ui.column().classes("w-full h-screen items-center justify-center gap-4") as top_screen:
    ui.label("アプリタイトル").classes("text-4xl font-bold")
    ui.button("スタート", on_click=show_main).classes("bg-blue-500 text-white p-4 rounded-lg")

# ========================================
# Main screen
# ========================================
with ui.column().classes("w-full min-h-screen items-center p-8 gap-4") as main_screen:
    ui.label("メイン画面").classes("text-3xl font-bold")
    id_input = ui.number("番号", value=1, min=1, precision=0)

    # Container for JSON content.
    content = ui.column().classes("gap-2")

    def load_data():
        content.clear()
        params = {"id": int(id_input.value)}
        response = requests.get(f"{API_URL}/item", params=params, timeout=5)
        response.raise_for_status()
        item = response.json()

        # Display content from data here.
        with content:
            if "error" in item:
                ui.label("見つかりません")
            else:
                ui.label(f"名前: {item['name']}")
                ui.label(item["message"])

    ui.button("データ読み込み", on_click=load_data).classes("bg-green-500 text-white p-2 rounded")
    ui.button("結果へ", on_click=show_result).classes("bg-purple-500 text-white p-4 rounded-lg mt-4")

# ========================================
# Result screen
# ========================================
with ui.column().classes("w-full h-screen items-center justify-center gap-4") as result_screen:
    ui.label("結果画面").classes("text-3xl font-bold")
    ui.label("ここに結果を表示")
    ui.button("もう一度", on_click=show_top).classes("bg-blue-500 text-white p-4 rounded-lg")

# ========================================
# Initial screen
# ========================================
show_top()

ui.run(host="127.0.0.1")

実装の進め方

  1. api.py を起動し、ブラウザで http://127.0.0.1:8000/api/item?id=1 を確認
  2. main.py を起動し、3画面の遷移と「データ読み込み」を確認
  3. data.json に企画に必要なデータを記述
  4. データを表示・処理するコードを追加
  5. ワイヤーフレームをもとに、画面・ボタン・配置を変更
  6. zipにして別のフォルダに解凍し、動作確認後に提出

動かないとき

  • api.py を変更したら、Ctrl + C で止めて起動し直す（main.py と違い自動では再起動しない）
  • 「データ読み込み」で何も表示されないときは、api.py の起動を確認する（エラーは main.py のターミナルに出る）
  • data.json は保存すれば、次の読み込みから反映される
