提出物：zipに4点

  • ファイル名は 「学籍番号_名前.zip」
内容 形式

2 Figmaで作った ワイヤーフレーム のスクショ PDF

4 アプリを紹介する スライド1枚（タイトル・特徴・スクショ程度でOK） PDF

3のzipは「入れ子」構造

.py と .json をまとめたzipを、提出zipの中に入れる。解凍して .py を実行するだけで動く ことを提出前に必ず確認する

ルール

  • テンプレートに付け足す形 で実装する
    • 文字・レイアウト変更、ボタン追加、遷移画面追加はOK
    • 構造を大きく変える／ライブラリを増やすのはNG
    • 生成AIの出力の丸写しはNG
  • 遷移画面は3画面以上
  • ライブラリは NiceGUI以外を追加しない
    • 授業で使ったもの（NumPy・Requestsなど）と、pip install不要の標準ライブラリ（mathなど）はOK
  • Figmaのモックと実装は、方向性が合っていれば同一でなくてよい（見た目に過度にこだわらない）
  • 人に聞くのはOK・助けるのは推奨 — 助けてもらったら紹介スライドに スペシャルサンクス を書く

いちばん大事なルール：データはJSONに

  • 表示するコンテンツは JSONに書き、APIから取得 する（テンプレートどおり HTTP経由 で）
    • JSONを編集するだけでアプリを変更・拡張できる 状態にする
    • 質問文や結果文を ui.label("...") に直接書かない（ハードコード禁止）
    • ボタンの「スタート」などコンテンツ以外のラベルはハードコードOK
  • （テンプレートは読み込みだけだが）JSONへの 書き込みもOK

なぜこのルールがあるのか

「データと画面の分離」は実務の鉄則。クイズを10問→100問にするのに コードを1行も触らない 設計が、良いアプリの証拠

評価基準

  • 提出物の内容とフォーマットが 指定通り
  • 公序良俗 に反していない
  • 生成AIの丸写しではなく、テンプレートに沿って 実装されている
  • エラーなく実行できる

減点されない技術

凝った機能より「指示通り・動く・分かる」が先。実行確認は zipを解凍し直した状態 でもう一度 — 「自分のPCでは動いた」の大半はファイルパスとファイル名の問題

テンプレートの構造

  • 3画面 = 3つの ui.column()。set_visibility() で1つだけ表示 して画面遷移に見せる

  • データファイルは data.json。この2つだけから始める
{
  "title": "サンプルタイトル",
  "message": "ここにメッセージが入ります"
}

画面切り替えの核心

def show_screen(screen_name):
    top_screen.set_visibility(screen_name == "top")
    main_screen.set_visibility(screen_name == "main")
    result_screen.set_visibility(screen_name == "result")

ui.button("スタート", on_click=lambda: show_screen("main"))
  • screen_name == "top" は True / False になる — 指定した画面だけ表示、他は非表示 が1行×3で書ける

lambda = その場で作る小さな関数

on_click には関数を渡す必要がある（show_screen("main") と書くと即実行されてしまう）。 lambda: show_screen("main") は「押されたら show_screen("main") を実行する 無名の関数」を作る書き方。 lambdaを避けたい人は、def show_main(): ... を画面の数だけ書く簡単版テンプレートを使えばよい

テンプレート全文

テンプレートと data.json を同じフォルダに置いて実行し、3画面が遷移すること・「データ読み込み」でJSONのタイトルが出ることを確かめてから改造を始めよ。

  • テンプレートの Path(__file__).parent は「この .py があるフォルダ」の意味 — どこから実行しても隣の data.json を見つけられる（「自分のPCでは動いたのに」事故の予防）

async / await は「待つ間、画面を止めない」書き方

テンプレートでは、HTTP通信をする load_data だけが async def（自作API+SPA で扱った形）。 改造で自分の関数を足すときは、通信しない関数なら普通の def でよい

テンプレート（API版）を表示 
"""
NiceGUI SPA テンプレート（API版）

3画面構成：トップ → メイン → 結果
JSONデータを自作APIからHTTP経由で取得して表示します。
"""

from nicegui import ui, app
from pathlib import Path
import json
import httpx

DATA_FILE = Path(__file__).parent / "data.json"   # この .py と同じフォルダの data.json

# ========================================
# APIエンドポイント
# ========================================
@app.get("/api/data")
def get_data():
    with open(DATA_FILE, "r", encoding="utf-8") as f:
        return json.load(f)

# ========================================
# 画面切り替え
# ========================================
def show_screen(screen_name):
    top_screen.set_visibility(screen_name == "top")
    main_screen.set_visibility(screen_name == "main")
    result_screen.set_visibility(screen_name == "result")

# ========================================
# 1. トップ画面
# ========================================
with ui.column().classes("w-full h-screen items-center justify-center gap-4") as top_screen:
    ui.label("アプリタイトル").classes("text-4xl font-bold")
    ui.button("スタート", on_click=lambda: show_screen("main")).classes("bg-blue-500 text-white p-4 rounded-lg")

# ========================================
# 2. メイン画面
# ========================================
with ui.column().classes("w-full min-h-screen items-center p-8 gap-4") as main_screen:
    ui.label("メイン画面").classes("text-3xl font-bold")

    # JSONデータを表示するコンテナ
    content = ui.column().classes("gap-2")

    async def load_data():
        content.clear()
        # 自作APIにHTTPリクエストを送ってデータを取得
        async with httpx.AsyncClient() as client:
            response = await client.get("http://localhost:8080/api/data")
        data = response.json()

        # TODO: ここでdataの内容を表示する
        with content:
            ui.label(f"タイトル: {data['title']}")

    ui.button("データ読み込み", on_click=load_data).classes("bg-green-500 text-white p-2 rounded")
    ui.button("結果へ", on_click=lambda: show_screen("result")).classes("bg-purple-500 text-white p-4 rounded-lg mt-4")

# ========================================
# 3. 結果画面
# ========================================
with ui.column().classes("w-full h-screen items-center justify-center gap-4") as result_screen:
    ui.label("結果画面").classes("text-3xl font-bold")
    ui.label("ここに結果を表示")
    ui.button("もう一度", on_click=lambda: show_screen("top")).classes("bg-blue-500 text-white p-4 rounded-lg")

# ========================================
# 初期表示
# ========================================
show_screen("top")

ui.run()

"""
NiceGUI SPA テンプレート（少し簡単版）

3画面構成：トップ → メイン → 結果
lambdaを使わず、画面ごとの関数で切り替えます。
"""

from nicegui import ui, app

    top_screen.set_visibility(True)

    result_screen.set_visibility(False)

    top_screen.set_visibility(False)
    main_screen.set_visibility(True)
    result_screen.set_visibility(False)

def show_result():
    top_screen.set_visibility(False)
    main_screen.set_visibility(False)
    result_screen.set_visibility(True)

# ========================================
# 1. トップ画面
# ========================================
with ui.column().classes("w-full h-screen items-center justify-center gap-4") as top_screen:
    ui.label("アプリタイトル").classes("text-4xl font-bold")
    ui.button("スタート", on_click=show_main)

# ========================================
# 2. メイン画面
# ========================================
with ui.column().classes("w-full min-h-screen items-center p-8 gap-4") as main_screen:
    ui.label("メイン画面").classes("text-3xl font-bold")

    # JSONデータを表示するコンテナ
    content = ui.column().classes("gap-2")

    async def load_data():
        content.clear()
        # 自作APIにHTTPリクエストを送ってデータを取得
        async with httpx.AsyncClient() as client:
            response = await client.get("http://localhost:8080/api/data")
        data = response.json()

        # TODO: ここでdataの内容を表示する
        with content:
            ui.label(f"タイトル: {data['title']}")

    ui.button("データ読み込み", on_click=load_data).classes("bg-green-500 text-white p-2 rounded")
    ui.button("結果へ", on_click=show_result)

# ========================================
# 3. 結果画面
# ========================================
with ui.column().classes("w-full h-screen items-center justify-center gap-4") as result_screen:
    ui.label("結果画面").classes("text-3xl font-bold")
    ui.label("ここに結果を表示")
    ui.button("もう一度", on_click=show_top)

# 初期表示
# ========================================
show_top()

進め方のおすすめ

  1. テンプレートを そのまま動かす（3画面の遷移と「データ読み込み」を確認）
  2. data.json を自分のテーマの内容に差し替える — コードは触らない
  3. メイン画面の TODO 部分を、自分のデータ構造に合わせて表示に変える
  4. 画面・ボタンを増やす（NiceGUI のスタイル早見表が武器庫）
  5. zipにして解凍し直し、まっさらな状態で動作確認 → 提出
