静的から動的へ

Plotlyとは

  • Plotlyは インタラクティブな可視化 を作るライブラリ
    • 拡大・縮小
    • ホバーで値を確認
    • 凡例クリックで表示・非表示
    • 3Dグラフを回転
  • matplotlibと同じく、Pythonから使える
  • Webページ上で動くHTMLとして出力できる

インストール ＆ import

  • pipからインストール
pip install plotly
  • importでは、可視化ツールを集めた plotly.express を px として読み込むのが一般的
import plotly.express as px

matplotlibとの違い

  • matplotlib：静的な図に強い
  • Plotly：Web上で動かせる図に強い
  • どちらが上ではなく、目的で使い分ける

この資料で扱うこと

  • plotly.express を使ってグラフを作る
  • Pandasの DataFrame と連携できることを理解
  • 棒グラフ・散布図・折れ線・ヒストグラム・3D散布図を作る
  • 最後に 世界一有名な「動くグラフ」 を手で作る

matplotlibとの「描き比べ」

  • 散布図・折れ線・ヒストグラムは matplotlibで一度作った図 ばかり
  • 同じ図を別の道具で作りながら、道具ごとの得意・不得意 を比べよう

棒グラフを作る

  • px.bar() で棒グラフを作る
  • x= と y= に列名を指定する
  • fig.show() で表示する
import plotly.express as px

fig = px.bar(df, x="名前", y="点数")
fig.show()

Plotly Expressの基本形

  • plotly.express は、短く書くための高レベルAPI
  • 基本形はどのグラフでも似ている

図にラベルとタイトルをつける

  • title= でタイトル
  • labels= で軸ラベルや凡例名を変えられる
  • labels には辞書を渡す
fig = px.bar(
    df,
    x="名前",
    y="点数",
    title="生徒ごとの点数",
    labels={"名前": "生徒", "点数": "得点"},
)
fig.show()

色分けする

  • color= に列名を指定すると、その列の値で色分けできる
  • カテゴリの違いを見せたいときに便利
fig = px.bar(
    df,
    x="名前",
    y="点数",
    color="学科",
    title="学科で色分けした点数",
)
fig.show()

何が便利？

  • 凡例をクリックすると、特定の学科だけ表示・非表示にできる
  • 棒にマウスを乗せると、値が表示される

ホバーで点を確認できる

  • 外れている点にマウスを乗せると 誰なのか その場で分かる
  • hover_name= を指定しておくと、点ごとの情報を探索しやすい

点のサイズはデータで可変にできる

  • size= に数値列を指定すると、点の大きさを変えられる
  • 位置（数学I・英会話）に加えて、欠席日数という別の量を大きさで重ねられる
  • 大きい点ほど欠席が多い — 成績との関係が見えるか？
fig = px.scatter(
    df_scores,
    x="数学I",
    y="英会話",
    color="学科",
    size="欠席日数",
    hover_name="名前",
)
fig.show()

自分の指でチェリーピックしてみる

  • ドラッグで2006〜2017年あたりを選択 してズーム →「寒冷化」に見える
  • 可視化編の騙しグラフは、この 切り取り と同じ操作だった
  • ダブルクリックで全体に戻る — 全体を確認するクセをつける

ズームアウト：80万年の気温

  • 南極の氷から復元した気温 — 80万年前まで遡れる（EPICA Dome C）。縦軸 0℃＝現在の水準（直近1000年の平均）、マイナスほど寒い
  • ドラッグでズーム → 氷期と間氷期を 約10℃も往復。東京150年の変化は、この巨大なリズムのごく一部
  • 同じ「気温」でも 見せるスパンで物語が変わる
  • データ：epica_temp.csv（data フォルダに置く）
df_temp_long = pd.read_csv("data/epica_temp.csv")
df_temp_long["万年前"] = df_temp_long["age_kyr_bp"] / 10  # 千年 → 万年 で読みやすく

fig = px.line(df_temp_long, x="万年前", y="temp_anomaly_c")
fig.show()

Pandasの集計結果をPlotlyへ

学科ごとの平均点を計算

  • Pandasで集計してからPlotlyで可視化する
  • Pandas入門と同じ data/students.csv を使う
  • groupby() の結果は Series
  • Plotlyに渡すため、いったん reset_index() でDataFrameに戻す
import pandas as pd

df_students = pd.read_csv("data/students.csv")
subjects = ["現代文", "数学I", "英会話", "物理"]

df_students["平均点"] = df_students[subjects].mean(axis=1)
avg = df_students.groupby("学科")["平均点"].mean()
print(avg)

SeriesをDataFrameに戻す

  • reset_index() で、indexを普通の列に戻せる
  • Plotly ExpressはDataFrame + 列名指定が書きやすい
import pandas as pd

df_students = pd.read_csv("data/students.csv")
subjects = ["現代文", "数学I", "英会話", "物理"]
df_students["平均点"] = df_students[subjects].mean(axis=1)
avg = df_students.groupby("学科")["平均点"].mean()

avg_df = avg.reset_index()
print(avg_df)
   学科        平均点
0  情報  80.062500
1  機械  71.625000
2  電気  77.583333
fig = px.bar(avg_df, x="学科", y="平均点")
fig.show()

集計結果をPlotlyで可視化

Plotly Expressに渡しやすい形

  • groupby() の結果は Series
  • reset_index() でDataFrameに戻すと、x="学科"、y="平均点" のように列名で指定できる

そのままDataFrameを作る方法

  • groupby(..., as_index=False) とすると、最初からDataFrameで結果を受け取れる
  • Plotlyで使う場合はこちらも便利
import pandas as pd

df_students = pd.read_csv("data/students.csv")
subjects = ["現代文", "数学I", "英会話", "物理"]
df_students["平均点"] = df_students[subjects].mean(axis=1)

avg_df = df_students.groupby("学科", as_index=False)["平均点"].mean()
print(avg_df)
   学科        平均点
0  情報  80.062500
1  機械  71.625000
2  電気  77.583333
fig = px.bar(avg_df, x="学科", y="平均点")
fig.show()

HTMLとして保存する

  • Plotlyの図は write_html() でHTMLとして保存できる
  • ブラウザで開けるので、相手に共有しやすい
fig.write_html("graph.html")
  • 何も指定しないと Plotly本体ごと HTMLに埋め込まれる（約4MB）
    • ファイルは重いが、ネットがなくても動く
  • ここまで触ってきた動くグラフも、こうして保存したHTMLの埋め込み

include_plotlyjs で本体の置き場所を選べる

指定 HTMLのサイズ 閲覧時のネット
（指定なし） 重い（約4MB） 不要
"cdn" 軽い 必要
"directory" 軽い（plotly.min.js を同じフォルダに書き出す） 不要

ネットのない場所でも動かしたい資料は、指定なし か "directory" を選ぶ

まず1年分だけ描いてみる

  • ここまでと同じ x, y, size, color, hover_name だけで散布図を作る
  • year 列で絞れば、1年分だけを取り出せる
gap_1952 = gap[gap["year"] == 1952]

    gap_1952,
    x="gdpPercap",
    y="lifeExp",
    size="pop",
    color="continent",

GDPは数百〜10万ドル超まで桁違いに広がり、ほとんどの国が左端に固まって見える

動くバブルチャートを簡単コーディング

  • year で絞る代わりに animation_frame="year" を渡すと、年ごとのコマがアニメーションになる
  • GDPの桁が国によって大きく違うので log_x=True で対数軸にする（さっきの偏りを解消）
fig = px.scatter(
    gap,
    x="gdpPercap",
    y="lifeExp",
    size="pop",
    color="continent",
    hover_name="country",
    log_x=True,
    size_max=55,
    animation_frame="year",
)
fig.show()
  • ▶ を押す と55年分の世界が動く（カーソルを合わせると国名が出る）

演習：学科ごとの平均点をPlotlyで描く

students.csv の学科ごとの平均点を、Plotlyの棒グラフで描け。

  1. data/students.csv を読み込み、4科目の平均点の列を追加
  2. groupby("学科", as_index=False) で学科ごとの平均点を集計
  3. px.bar() で棒グラフを描く（color="学科" で色分け、y軸は 0〜100）
解答例を見る 
import pandas as pd
import plotly.express as px

df = pd.read_csv("data/students.csv")
subjects = ["現代文", "数学I", "英会話", "物理"]

df["平均点"] = df[subjects].mean(axis=1)
avg_df = df.groupby("学科", as_index=False)["平均点"].mean()

fig = px.bar(
    avg_df,
    x="学科",
    y="平均点",
    color="学科",
    title="学科ごとの平均点",
)
fig.update_yaxes(range=[0, 100])
fig.show()

まとめ

  • Plotlyは インタラクティブな可視化 に強い
  • plotly.express は短いコードで書ける
  • 基本形は px.bar(df, x="列名", y="列名")
  • 色分けは color=
  • ホバー表示は hover_name=
  • Pandasの集計結果は、DataFrameにしてからPlotlyに渡すと分かりやすい
  • HTMLとして保存して、Webページに埋め込める
