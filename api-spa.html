自作APIとSPA

画面とデータを別のプログラムにする

  • API（Application Programming Interface）：プログラム同士がデータをやり取りする窓口
  • APIでデータ取得 では他のサービスのAPIを呼んだ。ここでは APIを自分で作り、自分の画面から呼ぶ

main.py と api.py は別々に起動するプログラム

REST API と HTTPメソッド

  • REST（Representational State Transfer）：Webサービスの設計様式
  • REST APIでは、URLで対象を表し、HTTPメソッド（HTTP method）で操作を表す
HTTPメソッド 用途 例
GET データを取得する 質問リストを取得
POST データを送信する 診断結果を保存
PUT データを置き換える プロフィール全体を更新
DELETE データを削除する アカウントを削除

質問リストや結果の取得には GET を使う

最小のAPIを作る

  • FastAPI：PythonでAPIを作るライブラリ（NiceGUIと一緒にインストールされる）
  • 次のコードを api.py として保存して実行する
from fastapi import FastAPI
import uvicorn

api = FastAPI()

def hello():
    return {"message": "Hello, API!"}

api.add_api_route("/api/hello", hello)

uvicorn.run(api, port=8000)

JSONファイルを読んで返す

from fastapi import FastAPI
from pathlib import Path
import json
import uvicorn

DATA_FILE = Path(__file__).parent / "questions.json"

api = FastAPI()

def get_questions():
    with open(DATA_FILE, "r", encoding="utf-8") as f:
        return json.load(f)

api.add_api_route("/api/questions", get_questions)

uvicorn.run(api, port=8000)
コード 機能
Path(__file__).parent このPythonファイルがあるフォルダ
open(DATA_FILE, "r", encoding="utf-8") 読み込みモードで開く（encoding で日本語対応）
json.load(f) JSONファイル → Pythonの辞書

http://127.0.0.1:8000/api/questions を開くと、JSONファイルの内容が返る

URLパラメータで指定した質問を返す

  • URLパラメータ（query parameter）：URLの ? の後ろに書く 名前=値
  • Wikipedia API の params= で渡していたもの
def get_question(id: int):
    for question in get_questions()["questions"]:
        if question["id"] == id:
            return question
    return {"error": "Not found"}

api.add_api_route("/api/question", get_question)
アクセスするURL 実行される処理
/api/question?id=1 get_question(id=1)
/api/question?id=2 get_question(id=2)
/api/question?id=999 {"error": "Not found"} を返す

URLの id=1 が、同じ名前の引数 id に入る。: int は 型ヒント（type hint）で、URLの文字列を整数に変換する

api.py の完成形

from fastapi import FastAPI
from pathlib import Path
import json
import uvicorn

DATA_FILE = Path(__file__).parent / "questions.json"

api = FastAPI()

def get_questions():
    with open(DATA_FILE, "r", encoding="utf-8") as f:
        return json.load(f)

def get_question(id: int):
    for question in get_questions()["questions"]:
        if question["id"] == id:
            return question
    return {"error": "Not found"}

api.add_api_route("/api/questions", get_questions)
api.add_api_route("/api/question", get_question)

uvicorn.run(api, port=8000)

画面からAPIを呼ぶ

  • 次のコードを main.py として、api.py と同じフォルダに保存する
from nicegui import ui
import requests

API_URL = "http://127.0.0.1:8000/api"

container = ui.column().classes("w-full gap-4 p-4")

def load_questions():
    container.clear()
    response = requests.get(f"{API_URL}/questions", timeout=5)
    response.raise_for_status()
    data = response.json()
    with container:
        ui.label(data["title"]).classes("text-3xl font-bold")
        for question in data["questions"]:
            with ui.card().classes("w-full"):
                ui.label(f"Q{question['id']}: {question['text']}").classes("font-bold")
                for choice in question["choices"]:
                    ui.label(f"・{choice}").classes("ml-4")

ui.button("質問を読み込む", on_click=load_questions)

ui.run(host="127.0.0.1")

api.py と main.py を起動する

  1. ターミナルで python api.py を実行する
  2. 別のターミナル で python main.py を実行する
  3. 開いた画面で「質問を読み込む」を押す
コード 機能
requests.get(url, timeout=5) APIを呼ぶ。5秒応答がなければエラーにする
response.raise_for_status() HTTPエラーを例外として通知する
response.json() JSONをPythonの値に変換する

動かないとき

  • 画面に何も表示されないときは、api.py の起動を確認する（エラーは main.py のターミナルに出る）
  • api.py を変更したら、Ctrl + C で止めて起動し直す（main.py と違い自動では再起動しない）

番号を指定して質問を取得する

  • URLパラメータは requests.get() の params= に渡す
from nicegui import ui
import requests

API_URL = "http://127.0.0.1:8000/api"

id_input = ui.number("質問の番号", value=1, min=1, precision=0)
container = ui.column().classes("w-full gap-4 p-4")

def load_question():
    container.clear()
    params = {"id": int(id_input.value)}
    response = requests.get(f"{API_URL}/question", params=params, timeout=5)
    response.raise_for_status()
    question = response.json()
    with container:
        if "error" in question:
            ui.label("その番号の質問はありません")
        else:
            ui.label(question["text"]).classes("text-xl font-bold")
            for choice in question["choices"]:
                ui.label(f"・{choice}").classes("ml-4")

ui.button("質問を読み込む", on_click=load_question)

ui.run(host="127.0.0.1")

ボタンを押すたびに取得し直す

  • container.clear()：前回の表示を消す
  • requests.get()：APIからデータを取得し直す
  • with container:：新しい内容を表示する

JSONを変更すると

APIは呼ばれるたびにファイルを読むので、questions.json を保存すると、次にボタンを押したときに新しい内容が表示される

（参考）@ で登録するコード

  • FastAPI の公式ドキュメントや多くのサンプルは、次の書き方を使っている
  • デコレータ（decorator）：@ で始まる行。すぐ下の関数に機能を追加する記法
@api.get("/api/hello")
def hello():
    return {"message": "Hello, API!"}

api.add_api_route("/api/hello", hello) と同じ登録をする

まとめ

  • api.add_api_route()：URLへのGETを処理する関数を登録
  • URLパラメータ：?id=1 の値が関数の引数に入る
  • requests.get()：画面のプログラムからAPIを呼ぶ
  • 表示の更新：container.clear() で消して、取得し直して表示
