自作APIとSPA

自分のアプリにAPIを付ける

  • APIを公開すると、他のプログラムからURLを指定してデータを取得できる
  • NiceGUI が使う FastAPI に、JSONを返すエンドポイントを追加する

REST API と HTTPメソッド

  • REST（Representational State Transfer）はWebサービスの設計様式
  • REST APIでは、URLで対象を表し、HTTPメソッド（HTTP method）で操作を表す
HTTPメソッド 用途 例
GET データを取得する 質問リストを取得
POST データを送信する 診断結果を保存
PUT データを置き換える プロフィール全体を更新
DELETE データを削除する アカウントを削除

質問リストや結果の取得には GET を使う

最もシンプルなAPI

from nicegui import ui, app

@app.get("/api/hello")
def hello():
    return {"message": "Hello, API!"}

ui.label("APIテスト")
ui.run()

@ の行の正体：デコレータ

  • @app.get(...) のような @ で始まる行を デコレータ（decorator）と呼ぶ
    • すぐ下の関数に特別な機能を追加する 記法
    • ここでは「この関数をAPIエンドポイントとして登録する」という意味
  • 関数名は自由。URLと結びつくのは デコレータの引数 のほう

関数を登録する

on_click=say_hi はボタン操作に関数を登録する。@app.get(...) は指定したURLへのGETに関数を登録する

画面からAPIのデータを表示する

from nicegui import ui, app
import json

@app.get("/api/questions")
def get_questions():
    with open("questions.json", "r", encoding="utf-8") as f:
        data = json.load(f)
    return data

def load_questions():
    data = get_questions()          # Call the API function directly.
    ui.label(data["title"]).classes("text-2xl font-bold")
    for question in data["questions"]:
        with ui.card().classes("w-full"):
            ui.label(f"Q{question['id']}: {question['text']}").classes("font-bold")
            for choice in question["choices"]:
                ui.label(f"・{choice}").classes("ml-4")

ui.button("質問を読み込む", on_click=load_questions).classes("bg-blue-500 text-white p-2 rounded")

ui.run()

なぜ関数を直接呼べるのか

  • 画面操作を処理する load_questions() と、API用の get_questions() は、どちらも Pythonサーバー側の関数
    • get_questions() を普通の関数として直接呼べる
    • この呼び出しではHTTP通信は発生しない
  • ブラウザはPythonサーバーとは別に動く
    • ブラウザから /api/questions を開いた場合は、HTTP通信でJSONを受け取る

戻り値の違い

直接呼ぶとPythonの辞書が返る。HTTPで呼ぶと、FastAPIが辞書をJSONに変換して応答する

HTTPでデータを取得する

  • httpx は、NiceGUIと一緒にインストールされるHTTPクライアント
  • 非同期処理（asynchronous processing）では、通信の応答を待つ間に他の処理を進められる
書き方 意味
async def await を使える関数を定義
async with httpx.AsyncClient() as client: 非同期のHTTPクライアントを作り、使用後に閉じる
await client.get(...) 応答を待つ間、他の処理に実行を譲る

非同期のコールバックで取得する

async def の関数も on_click に登録できる。raise_for_status() はHTTPエラーを例外として通知する

from nicegui import ui, app
import json
import httpx

@app.get("/api/questions")
def get_questions():
    with open("questions.json", "r", encoding="utf-8") as f:
        return json.load(f)

async def load_questions():
    async with httpx.AsyncClient() as client:
        response = await client.get("http://localhost:8080/api/questions")
        response.raise_for_status()
    data = response.json()
    ui.label(data["title"]).classes("text-2xl font-bold")

ui.button("HTTPで読み込む", on_click=load_questions)
ui.run()

同期通信で処理が止まる理由

コールバック内の同期通信

requests.get() をここに直接書くと、応答待ちでNiceGUIのイベントループが止まる。自分のサーバーも応答を処理できなくなるため、この例では httpx + await を使う。外部APIが相手でも、コールバック内の通信は非同期にする

エンドポイント追加の解答例を表示 
from nicegui import ui, app
import json

def read_data():
    with open("questions.json", "r", encoding="utf-8") as f:
        return json.load(f)

@app.get("/api/questions")
def get_questions():
    return read_data()

@app.get("/api/results")
def get_results():
    return read_data()["results"]

@app.get("/api/questions/{question_id}")
def get_question(question_id: int):
    for question in read_data()["questions"]:
        if question["id"] == question_id:
            return question
    return {"error": "Not found"}

container = ui.column().classes("w-full gap-4 p-4")

def load_data():
    container.clear()
    data = get_questions()
    with container:
        ui.label(data["title"]).classes("text-3xl font-bold mb-4")
        for question in data["questions"]:
            with ui.card().classes("w-full"):
                ui.label(f"Q{question['id']}: {question['text']}").classes("font-bold text-lg")
                for choice in question["choices"]:
                    ui.label(f"・{choice}").classes("ml-4")

ui.button("質問を読み込む", on_click=load_data).classes("bg-blue-500 text-white p-3 rounded-lg")
ui.run()
