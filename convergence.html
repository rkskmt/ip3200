KJ法（Kawakita Jiro Method）

写真: Parul Vora, CC BY-SA 3.0, via Wikimedia Commons

  • 日本の文化人類学者 川喜田二郎（1920–2009）が考案した 発想整理の方法
    • 「KJ」は本人のイニシャル。著書『発想法』（1967）で広まった
  • もとは、ネパール山岳地帯などのフィールドワークで得た 大量の観察メモを構造化して洞察を得る ための研究手法
    • のちにビジネス・教育の場で、アイデア整理の定番になった
  • 写真は、まさにKJ法の最中の壁 — かたまりが生まれ始めている

KJ法のいろいろな呼び名

名称 意味・出典
KJ法 川喜田二郎の『発想法』による正式名称
親和図法（Affinity Diagram） 海外での一般的な呼び方 — 「親和性」でまとめる図
カード法 アイデアをカード・付箋に書いて動かす形式から
  • 呼び名は違っても中身は同じ — 海外のUXの現場でも「affinity diagramming」として日常的に使われている

KJ法の手順

  1. カード化 — 意見・事実・観察を 1枚1件 でカード（付箋）に書く
  2. グルーピング — 意味の近さ（親和性）でカードを寄せる
  3. 中見出しづけ — 各グループの意味を表す短いフレーズを付ける
  4. 構造化 — グループ同士の上位・下位、因果を矢印で結ぶ
  5. 総合化 — 全体の構造を図や文章にする（→ レポート・企画書へ）

完成した「KJ図」のかたち

図: Jpz, CC BY-SA 3.0, via Wikimedia Commons（品質管理学者・司馬正次が描くKJ図の複製）

  • グループに 中見出し、グループ間に 矢印（因果・流れ）
  • バラバラの付箋の山が「1枚の構造」になる のがゴール

カードに名前は書かない

  • KJ法の特徴的なルール：個別のカードに書いた人の名前を入れない
    • 「誰の意見か」が見えると、内容ではなく人 で判断してしまう
    • 主観を外し、データそのものに語らせるのが狙い

己れを空しくして、データをして語らしめる

── 川喜田二郎『発想法』

参画意識という副作用

全員の付箋が同じ資格で1枚の図になるため、「参加した」ではなく 「一緒に作った」 という意識が生まれる — KJ法の隠れた効果

KJ法を使う場面と道具

  • 使う場面
    • 実験・プロジェクトテーマの 問題構造の分析
    • アイデアソンやチーム開発の 要件整理
    • フィールド調査のまとめ（観察 → 洞察）
ツール 活用法
付箋 + 模造紙 アナログKJ法の基本スタイル。物理的に動かせる強さ
Miro などのオンラインホワイトボード デジタル親和図。離れていても同時にグループ化できる

演習 KJ法

発想法の演習で出した付箋（ブレスト・635法の全案）をKJ法で整理し、模造紙1枚の「KJ図」に仕上げよ。

  1. 付箋を全部テーブルに広げる（名前は書かない・消す）
  2. 近い意味の付箋を寄せてグループ化（3〜7枚 目安、無理に全部入れない）
  3. 各グループに中見出し（短いフレーズ）
  4. グループ間の関係を矢印で記入（原因→結果、手段→目的）
  5. 図全体を1文で要約して余白に記入

先に見出しを作らない

「勉強系」「生活系」のような 箱を先に決めて仕分ける のはKJ法ではない。 カードを読んで、寄ってきたかたまりに後から名前を付ける

アイデアマップ（マインドマップ）

アイデアマップ：放射状に整理する

図: Danny Stevens, CC BY 2.5, via Wikimedia Commons

  • イギリスの教育家 トニー・ブザン（Tony Buzan、1942–2019）が1970年代に考案
  • 中心から枝を伸ばす 放射思考（Radiant Thinking）のノート法
    • 「脳は線形ではなく放射的に考える」がブザンの主張

アイデアマップの描き方

  1. 中心にテーマを 文字 + イメージ で描く（例：「文化祭」）
  2. 第一枝（主要要素）を放射状に伸ばす — 「企画」「準備」「装飾」「宣伝」
  3. 第二枝・第三枝で詳細化 — 「宣伝」→「ポスター」「SNS」「動画」
  4. 色・絵・記号で分類と強調
  5. 全体を俯瞰して、枝どうしの意外なつながり を探す

名前と商標の注意

名称 内容
Mind Map®（マインドマップ） ブザン側の 登録商標。商用利用（講座名・商品名）では表記に注意
アイデアマップ／思考マップ 商標を避けた代替名称。多くのアプリがこちらを採用
概念マップ（Concept Map） 研究・教育心理学の近縁技法。枝の関係にラベルを付けて厳密に定義する点が違う
  • 授業・ノートなど非商用の範囲では「マインドマップ」と呼んで問題ない

マインドマップ vs KJ法

マインドマップ KJ法
発案者 トニー・ブザン（英国） 川喜田二郎（日本）
目的 個人 の思考整理・発想 チーム のアイデア統合・構造化
構造 放射型（中心 → 枝） 集合型（カード → グループ）
思考タイプ 発散 + 整理の中間 収束（意味づけ）
使う場面 ノート・構想・自己分析 チーム発表・レポート構造

使い分けの目安

1人なら マインドマップ、チームなら KJ法。個人で枝を広げてから、チームで付箋にして持ち寄る合わせ技も定番

演習 アイデアマップ

「自分のアプリのアイデア」を中心に置き、第一枝4本以上・第二枝まで含めて20ノード以上のアイデアマップを紙1枚に描け（色は3色以上）。

  1. A4を横置きにして中心にテーマを描く（絵があるとよい）
  2. 第一枝：「誰が使う」「何ができる」「画面」「データ」など4本以上
  3. 各枝に第二枝を2本以上
  4. 描き終えたら俯瞰し、離れた枝同士のつながり を点線で1本以上引く

この地図は最終課題まで使う

ここで描いたマップが、ワイヤーフレーム（Figma）と実装（NiceGUI）の設計図の種になる

発散から収束へ：全体の流れ

  • 量を出す（発散）→ 見える化（マップ）→ 構造化（KJ法）ときて、最後は どれをやるか決める
    • 次は ペイオフマトリクス で 優先順位 を付ける
