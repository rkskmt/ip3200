なぜオープンデータか

オープンデータとは

  • 政府・自治体が 誰でも自由に使える形式 で公開するデータ
  • 商用・非商用問わず 二次利用可能
  • 機械可読（CSV, JSON, API）で提供

意義

  • 透明性：行政の活動を市民が検証できる
  • イノベーション：民間がデータを活用してサービス開発
  • 効率化：データに基づく政策立案（EBPM: Evidence-Based Policy Making）

身近なオープンデータ活用例

サービス 使用データ
乗換案内アプリ 公共交通の時刻表・遅延情報
防災アプリ 避難所・ハザードマップ
不動産サイト 地価公示・用途地域
天気予報 気象庁の観測データ
  • すでに使っている — 意識していないだけ
  • 自分でもAPIを叩けば 同じデータ が手に入る

東京都オープンデータAPI

概要

  • 東京都オープンデータカタログサイト の一部データをAPI提供
  • ユーザ登録 不要 — 誰でもすぐに利用可能
  • 掲載データ約54,000件のうち、CSV約35,000件がAPI対応
項目 内容
認証 不要
レート制限 明示なし（常識的な範囲で）
データ形式 JSON / XML
CORS 対応済み

Wikipedia APIとの違い

Wikipedia API 東京都API
HTTPメソッド GET POST
データ内容 百科事典・統計 行政・地理・施設
更新頻度 リアルタイム〜日次 不定期（年次も多い）

重要：POSTでアクセス

  • Wikipedia API は requests.get()
  • 東京都API は requests.post()
  • 間違えると動かない

APIの構造

基本URL

https://service.api.metro.tokyo.lg.jp/api/{apiId}/{format}
  • {apiId} — データセットごとに異なるID
  • {format} — json または xml

例：東京都人口の推移（JSON）

https://service.api.metro.tokyo.lg.jp/api/t000003d2000000236-c054eb26d9e9721642bef78c7c717e76-0/json

APIのIDを探す

  • API検索ページ でキーワード検索
  • 欲しいデータの apiId をコピーして使う

探し方のコツ

  • 「避難所」「駐輪場」「人口」などキーワードで検索
  • 区市町村名で絞り込み可能
  • 詳細ページで apiId と列名を確認

パラメータ

パラメータ 説明 例
limit 取得レコード数の上限 ?limit=100
offset 取得開始位置 ?offset=50
column 取得する列の指定 ?column=名称,住所
filter 条件フィルタ ?filter=公表_年月日:2021
  • デフォルトは 100件
  • 全件欲しいときは limit を大きく設定

基本的な使い方

最小テンプレート

import requests

api_id = "t000003d2000000236-c054eb26d9e9721642bef78c7c717e76-0"
url = f"https://service.api.metro.tokyo.lg.jp/api/{api_id}/json"

params = {"limit": 200}
headers = {"User-Agent": "example.com/lesson"}
body = {}

response = requests.post(url, params=params, headers=headers, json=body)
data = response.json()

print(data["hits"])

json={} の意味

  • 空のJSONボディを送信している
  • 東京都APIの仕様上必要
  • 深い意味はないが省略不可

レスポンス構造

{
  "total": 152,
  "subtotal": 152,
  "limit": 200,
  "offset": null,
  "metadata": {
    "apiId": "API識別子",
    "title": "データタイトル",
    "version": "1.0.7"
  },
  "hits": [
    {"row": 1, "和暦（年次）": "明治5", "西暦（年次）": 1872, "東京都／人口": 859345},
    {"row": 2, "和暦（年次）": "明治6", "西暦（年次）": 1873, "東京都／人口": 887322},
    ...
  ]
}
  • total — 全件数
  • metadata — データセットの情報
  • hits — 実際のデータ本体（list of dict）

検索条件を指定する

body で条件指定

  • column — 取得する列を限定
  • searchCondition — フィルタ条件（APIによって対応状況が異なる）
# 列を限定して取得
body = {
    "column": ["西暦（年次）", "東京都／人口"]
}

# 取得後に Python でフィルタリング
filtered = [r for r in data["hits"]
            if 1950 <= r["西暦（年次）"] <= 2023]

比較演算子

演算子 意味 数式
gt greater than > より大きい
lt less than < より小さい
ge greater or equal ≥ 以上
le less or equal ≤ 以下

覚え方

  • g = greater（大きい）
  • l = less（小さい）
  • e = equal（等しい）

NumPyで統計処理

統計分析の例

  • 外部APIのデータは型が揃っているとは限らない — 使う前に型を確認すると安全
  • isinstance(値, int) で「int型かどうか」を判定できる
import requests
import numpy as np

headers = {"User-Agent": "example.com/lesson"}
api_id = "t000003d2000000236-c054eb26d9e9721642bef78c7c717e76-0"
url = f"https://service.api.metro.tokyo.lg.jp/api/{api_id}/json"

params = {"limit": 200}
response = requests.post(url, params=params, headers=headers, json={})
data = response.json()

# 人口を抽出（int型の値だけ使う）
population = [r["東京都／人口"] for r in data["hits"]
              if isinstance(r.get("東京都／人口"), int)]
population = np.array(population)

print(f"平均: {np.mean(population):,.0f}人")
print(f"最大: {np.max(population):,}人")
print(f"最小: {np.min(population):,}人")
print(f"標準偏差: {np.std(population):,.0f}")
print(f"中央値: {np.median(population):,.0f}人")
平均: 7,294,170人
最大: 14,099,993人
最小: 859,345人
標準偏差: 4,567,885
中央値: 7,189,875人

まずは可視化する

  • 数値だけでは傾向がわからない
  • visualize章 の原則：Always plot your data first.
  • 右肩上がり — 150年で約16倍に増加
  • 1940年代に急落 — 戦争による疎開・被害
  • 2020年代は横ばい — コロナ禍の2021年には減少もあった

これまでの章が活きる

  • list章 の内包表記で抽出
  • numpy章 の統計関数で集計
  • visualize章 の手法で可視化

演習：人口推移の時系列グラフ

東京都の人口データを全件取得し、人口推移を折れ線グラフで描け。

  1. 年と人口を取り出して 折れ線グラフ を描画
  2. 最大値・最小値・平均 をタイトルに表示
解答例を見る 
import requests
import numpy as np
import matplotlib.pyplot as plt
import japanize_matplotlib

headers = {"User-Agent": "example.com/lesson"}
api_id = "t000003d2000000236-c054eb26d9e9721642bef78c7c717e76-0"
url = f"https://service.api.metro.tokyo.lg.jp/api/{api_id}/json"

params = {"limit": 200}
response = requests.post(url, params=params, headers=headers, json={})
data = response.json()

years = np.array([r["西暦（年次）"] for r in data["hits"]
                  if isinstance(r.get("東京都／人口"), int)])
population = np.array([r["東京都／人口"] for r in data["hits"]
                       if isinstance(r.get("東京都／人口"), int)])

plt.figure(figsize=(10, 4))
plt.plot(years, population / 1e6)
plt.title(f"Max={np.max(population):,}, Min={np.min(population):,}, Mean={np.mean(population):,.0f}")
plt.xlabel("Year")
plt.ylabel("Population (million)")
plt.grid(True, linestyle="--", alpha=0.5)
plt.show()

演習：2つのデータセットを比較

異なる2つのデータセット（例：2つの区の避難所、戦前と戦後の人口）を取得し、件数や統計量を比較して表示せよ。

  • （発展）同じグラフに重ねて描画
解答例を見る（戦前と戦後の人口を比較する例） 
import requests
import numpy as np

headers = {"User-Agent": "example.com/lesson"}
api_id = "t000003d2000000236-c054eb26d9e9721642bef78c7c717e76-0"
url = f"https://service.api.metro.tokyo.lg.jp/api/{api_id}/json"

response = requests.post(url, params={"limit": 200}, headers=headers, json={})
hits = response.json()["hits"]

prewar  = np.array([r["東京都／人口"] for r in hits if r["西暦（年次）"] <= 1944])
postwar = np.array([r["東京都／人口"] for r in hits if r["西暦（年次）"] >= 1946])

print(f"戦前（〜1944）: {len(prewar)}年分 平均 {prewar.mean():,.0f}人")
print(f"戦後（1946〜）: {len(postwar)}年分 平均 {postwar.mean():,.0f}人")
